# EnekoCoin Live-Platform Starter

Run:
1. Install Node.js 18+
2. `npm install`
3. Copy `.env.example` to `.env`
4. Set a strong JWT_SECRET
5. `npm start`
6. Open http://localhost:3000

This is a sandbox starter, not a licensed financial service. It includes authentication, password hashing, JWT sessions, SQLite balances, markets, transactions and paper trading.

Before real-money use: add hardened production infrastructure, secure secrets, rate limiting, database backups/migrations, KYC/AML and sanctions controls, custody/payment/trading providers, reconciliation, monitoring, incident response, independent security testing, and all required legal/regulatory authorization.

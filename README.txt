ENEKOCOIN FULL DEMO
===================
Open index.html in a browser.

Included:
- Responsive landing/dashboard UI
- Portfolio overview and chart
- Markets with search
- Wallet balances and transaction-style activity
- Paper-trading buy/sell interface
- Referral dashboard
- Security settings UI
- Admin dashboard demo
- Mobile navigation
- Toast notifications

IMPORTANT:
This is a front-end demonstration. It does not process real money or
cryptocurrency and should not be represented as a live exchange. A real
launch requires secure backend infrastructure, authentication, database,
audited smart contracts where applicable, market-data services, wallet/custody
architecture, payment rails, monitoring, legal/compliance review and any
licenses required in the jurisdictions where it operates.
